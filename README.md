# bestfrend — make one

Spin a 3D tee, drop on a design, stack patterns, pick your inks. Every one is one of one.

**Play:** open `index.html` — that's the whole app. No build, no install.

**Deploy:** drag `index.html` onto [Netlify Drop](https://app.netlify.com/drop), or enable GitHub Pages on this repo (Settings → Pages → main branch).

**Add to phone:** open the live link in Safari/Chrome → Share → Add to Home Screen.
